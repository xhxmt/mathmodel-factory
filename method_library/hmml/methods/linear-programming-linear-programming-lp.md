## 建模方法

Linear Programming (LP) is a mathematical optimization method used to maximize or minimize a linear objective function subject to a set of linear constraints.

## 核心思想

It helps decision-makers achieve optimal decisions under limited resources.

## 典型应用

It is widely used in resource allocation, production planning, and transportation scheduling.
