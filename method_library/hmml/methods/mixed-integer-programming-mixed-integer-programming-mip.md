## 建模方法

Mixed Integer Programming (MIP) is an optimization method that combines the characteristics of linear programming and integer programming, allowing some decision variables to be integers.

## 核心思想

It integrates both continuous and discrete decision variables to solve complex optimization problems.

## 典型应用

It is widely used in production scheduling, logistics optimization, and facility location.
