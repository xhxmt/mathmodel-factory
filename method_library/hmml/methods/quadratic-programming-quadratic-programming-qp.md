## 建模方法

Quadratic Programming (QP) is an optimization method aimed at solving problems where the objective function is quadratic and the constraints are linear.

## 核心思想

It involves constructing a Lagrangian function and utilizing the Karush-Kuhn-Tucker (KKT) conditions to find the optimal solution.

## 典型应用

Quadratic Programming is extensively applied in financial engineering (such as portfolio optimization and risk management), machine learning (such as support vector machines), control theory (such as model predictive control), and engineering optimization (such as structural design and resource allocation).
